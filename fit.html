Where fittings go

Each saved fitting lands in the ForeUnder Fit Records Google Sheet. Saving again from this screen updates the same fitting. Your draft is kept on this device until you start a new fitting.

Standards used. Starting length and lie: PING Color Code Chart and PING fitting manual (each color code is 1° of lie). Grip size: Golf Pride Grip Size Guide. Driver launch and spin windows: published TrackMan data. Starting flex: general industry swing-speed charts (iron bands scaled from driver bands by the typical 7-iron to driver speed ratio). Weight and tempo adjustments: ForeUnder fitter guidelines, confirmed by testing. Ball data: Garmin Approach R10.
